# release-cadence-survey-2026

This repository holds **release-process research for an internal lunch-and-learn talk** on how mature open-source projects actually ship releases.

Instead of anecdotes, the survey in [`SURVEY.md`](SURVEY.md) records real, current release data — latest stable release tag, publish date, the commit each release tag points to, and whether the release immediately before it was flagged as a prerelease — for a set of well-known open-source projects.

## Contents

- [`SURVEY.md`](SURVEY.md) — the survey data, one section per project.
- One tracking issue per surveyed project, titled `Survey: <owner>/<repo>`.

## Projects surveyed

- vuejs/core
- vercel/next.js
- electron/electron
